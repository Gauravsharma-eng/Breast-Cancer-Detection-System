🔬 Advanced Breast Cancer Detection System
An AI-powered application for detecting breast cancer tumors in medical images using YOLOv5 and EfficientNet. The app supports image upload and webcam capture, provides real-time detection visualization, and includes multiple image preprocessing options for accurate results.

This project is designed for research purposes and early detection support for healthcare professionals.

🎯 Features

Multiple AI Models:

Custom YOLOv5 for specialized tumor detection

Pre-trained YOLOv5

EfficientNet for classification

Flexible Input Options: Upload images or use webcam

Advanced Preprocessing: CLAHE, contrast enhancement, sharpening, grayscale conversion

Real-Time Detection: Bounding boxes with confidence scores

User-Friendly UI: Streamlit app with light/dark mode
